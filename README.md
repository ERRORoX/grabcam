# GrabCam v2.0 — consent-first camera demo

Учебный проект для демонстрации браузерного доступа к камере с явным согласием пользователя.

## Возможности
- камера запускается только после нажатия кнопки и системного разрешения браузера;
- перед запуском пользователь отдельно подтверждает автоматическую съёмку раз в 5 секунд;
- перед запуском пользователь отдельно подтверждает автоматическую передачу снимков на сервер;
- видео с камеры остаётся видимым на странице;
- съёмку можно остановить в любой момент;
- PHP сохраняет JPEG-файлы в папку `Photo/` с непредсказуемыми именами;
- нет сбора паролей, скрытого доступа к галерее или фонового получения геолокации.

## Требования
- PHP 8.0+;
- современный браузер;
- HTTPS для удалённого доступа (для локального теста подходит localhost).

## Запуск в Kali Linux / Linux / Termux
```bash
git clone https://github.com/ERRORoX/grabcam.git
cd grabcam
git checkout exam-safe-v2
chmod +x grabcam.sh
./grabcam.sh
```

Откройте `http://127.0.0.1:3333`.

Для доступа с другого устройства браузеру нужен HTTPS. Не публикуйте папку `Photo/` напрямую в открытый веб-каталог.

## Поток работы
1. Пользователь открывает страницу и читает уведомление.
2. Отмечает согласие на периодические снимки.
3. Отдельно отмечает согласие на передачу снимков серверу.
4. Нажимает кнопку запуска и подтверждает запрос камеры в браузере.
5. Страница делает снимки с интервалом 5 секунд и отправляет их в `post.php`.
6. Кнопка «Остановить» прекращает съёмку и закрывает поток камеры.

## Серверное хранение
`post.php` принимает только POST JPEG до 5 МБ, проверяет фактический тип изображения и сохраняет файл в `Photo/`. Имена файлов генерируются сервером. Для реального развёртывания настройте авторизацию администратора, ограничение частоты запросов и хранение каталога вне публичного web root.

## Безопасность
Не используйте проект для съёмки или сбора данных людей без их осознанного согласия. Не добавляйте скрытый захват, подмену страниц входа или сбор учётных данных.
