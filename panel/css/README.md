# Модульные стили Grabcam

Подключается один файл: **tool-grabcam.css** — он подтягивает остальные через `@import`.

## Файлы

| Файл | Назначение |
|------|------------|
| **tool-grabcam.css** | Точка входа: только импорты |
| **base.css** | Переменные (`--gc-*`), сетка, общие карточки, медиа-запросы |
| **shared.css** | Общие компоненты: кнопки, переключатели, метрики, списки, таблицы |
| **standalone-extra.css** | Стили только для автономного запуска (шапка, body) |

## Папка widgets/

Один файл = одна карточка. Меняешь карточку — правишь только её файл.

| Файл | Карточка |
|------|----------|
| **control.css** | Управление (туннель, кнопки старт/стоп) |
| **summary.css** | Сводка сессии (длительность, цели, уник. IP) |
| **link.css** | Публичная ссылка, копирование |
| **map.css** | Карта местоположений |
| **photos.css** | Фото (сетка превью) |
| **locations.css** | Список местоположений |
| **forms.css** | Захваты форм |
| **screen.css** | Захват экрана |
| **audio.css** | Аудио |
| **summary-text.css** | Текстовая сводка |

## Как править размер/вид карточки

- **Сводка сессии** — `widgets/summary.css`, блок `#panel-grabcam .gc-widget-summary` (например, `max-width`, `justify-self`).
- **Любая другая карточка** — открой соответствующий файл в `widgets/` и меняй стили там.
